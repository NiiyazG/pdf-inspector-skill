# PDF Inspector

Анализ и извлечение содержимого PDF-документов. Лёгкий, локальный,
переносимый скилл — на любом агенте/сервере с Python.

## Возможности

- **Метаданные** — автор, дата создания, producer, прочие свойства PDF.
- **Число страниц** — общее количество страниц документа.
- **Извлечение текста** — весь читаемый текст из PDF (постранично).

## Быстрый старт

```bash
# 1. Зависимость (PyMuPDF)
pip install -r requirements.txt   # или: pip install pymupdf

# 2. Запуск
python3 scripts/inspect.py "/path/to/document.pdf"
```

## Пример вывода (JSON)

```json
{
  "filename": "document.pdf",
  "pages": 12,
  "metadata": {
    "author": "...",
    "creationDate": "...",
    "producer": "..."
  },
  "text_content": "Полный текст документа..."
}
```

## Интеграция с другими инструментами

Скилл возвращает валидный JSON — удобно передавать вывод в другие скрипты
(например, в Memory Stack для индексации PDF-документов: `ingest.py` уже
умеет читать PDF, если доступен PyMuPDF).

## Структура

```
pdf-inspector-skill/
├── SKILL.md            # этот документ

├── requirements.txt    # pymupdf
└── scripts/
    └── inspect.py      # основной скрипт
```

## Как это устроено

`scripts/inspect.py` использует **PyMuPDF** (`fitz`):
1. Открывает PDF по переданному пути.
2. Читает метаданные и счётчик страниц.
3. Извлекает текст со всех страниц.
4. Возвращает JSON: `{filename, pages, metadata, text_content}`.

При ошибке (например, повреждённый файл) возвращает `{"error": "..."}`.

## Зависимости

- Python 3.8+
- PyMuPDF (`pymupdf`) — единственная библиотека

```bash
pip install pymupdf
```

## Безопасность и переносимость

- **Без личных данных** — скилл не содержит данных пользователя, только код.
- **Локально** — без внешних API и сети, всё на машине.
- **Переносимо** — путь к PDF передаётся аргументом, жёстких абсолютных
  путей в коде нет. Путь в команде запуска указывайте относительно вашей
  папки скилла.
